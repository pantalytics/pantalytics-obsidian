# The corner's panel: vault and note (27-11-2026)

The design the owner signed off on 27-11-2026 on the canvas
[Knap corner: vault and note](https://claude.ai/artifact/F4X7PoUcvdLzPk5EKicCyR).
It replaces the corner's menu of [2026-11-26](../2026-11-26/README.md); the
sidebar, the version tab and Restore from that day are unchanged. What ships is
described in [../../ui-ux.md](../../ui-ux.md), "The corner of the window".

| Board | What |
|---|---|
| `Main` | Click the corner: the vault (word, when or how much, Try again under Problem), then the open note (its own word, the reason when it could not sync, Last changed, Created, Version history). Switch the vault and note states in Tweaks. |
| `Phone` | No status bar on a phone: the icon in the note's header opens the same panel as a sheet. |

`screenshots/` are the real plugin in Obsidian against a local vault service
(dev login), when present.
